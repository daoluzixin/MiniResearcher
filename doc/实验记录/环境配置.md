## 八、已知问题与注意事项

1. **系统 RAM 最低 32GB**：16GB 会导致 Ray worker 被 OOM killer 杀掉（训练时 CPU 端需加载 ref model 等）。

2. **`agent_grpo.n` 必须显式设置**：默认值是 2，如果 `rollout.n=4` 但 `agent_grpo.n=2`，会导致 batch size 不匹配报错。两者必须一致。

3. **`gpu_memory_utilization=0.3` 是安全值**：对应约 24GB KV cache。降到 0.2 仍然 OOM 说明不是 GPU 显存问题而是系统 RAM 问题。

4. **SwanLab 可视化**：实验自动同步到 https://swanlab.cn/@Fyrgo/verl_examples，可在线查看曲线。

5. **每次实验前清理旧 checkpoint**：`rm -rf /root/DeepResearcher/ckpts/verl_examples/gsm8k/global_step_*`，否则显存不够。
